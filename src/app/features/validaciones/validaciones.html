7. Reglas de Validación Críticas (MUV)

El Motor Único de Validación (MUV) aplica reglas estrictas para mantener la consistencia en el ecosistema nacional.

Validación de Paciente (MPI EVOL)

Para ciudadanos colombianos, el tipo y número de documento, nombres y apellidos, y sexo biológico enviados deben coincidir exactamente con la Registraduría Nacional (Registro EVOL). Las inconsistencias provocarán rechazo automático (HTTP 400). Para extranjeros o no identificados, se omite esta validación y se crea el registro temporal.

Duplicidad (Error 409 Conflict)

Si un envío de Encounter tiene exactamente el mismo subject, period, serviceProvider y participant de uno ya existente en la base de datos central, el sistema retornará un error 409 Conflict.

OperationOutcome (Respuestas MUV)

Todos los rechazos o confirmaciones devolverán un recurso FHIR OperationOutcome. Este especificará el nivel de severidad (error/warning), el código del fallo y la ubicación exacta (Path JSON) del campo inválido.
