Reglas Generales de Programación

1

Vacíos en JSON RIPS

Cuando un campo no tenga información y sea opcional, se debe imprimir exactamente la palabra null (sin comillas dobles) en el JSON.

2

Vacíos en JSON RDA (FHIR)

3

Números y Ceros

  • Los campos numéricos financieros no pueden ser negativos.
  • Si la atención no genera cobro (ej. cápita), el valor debe ser estrictamente 0 (cero, sin comillas).
  • No se deben usar puntos separadores de miles.

Observación para Arquitectos Backend

Al usar /Composition/$enviar-rda-paciente y /Composition/$enviar-rda-urgencias, mapear los códigos HTTP:

200
OK

El RDA se guardó con éxito. Retorna identificador VIDA.

400
Bad Request

Falló validación de estructura. Revisar OperationOutcome.location.

409
Conflict

Duplicidad. Rechaza si ya existe atención con mismo subject + period + serviceProvider + participant.
