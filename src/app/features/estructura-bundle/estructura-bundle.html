Arquitectura de Seguridad — Cumplimiento Normativo

Requisitos estrictos de seguridad según la norma técnica del Ministerio y la Ley 1581 de 2012 (Habeas Data).

1. No exponer credenciales (BFF Pattern)

El frontend NUNCA almacena client_id, client_secret ni Ocp-Apim-Subscription-Key. Se resuelven desde Azure Key Vault vía un BFF.

2. Cabeceras HTTP y Cifrado en Tránsito (TLS 1.2+)

Toda comunicación fuerza https://. Se inyectan los headers Authorization, Ocp-Apim-Subscription-Key y Content-Type: application/fhir+json.

3. Cifrado en Reposo (AES-256-GCM)

Si el navegador pierde conectividad, el JSON se cifra con AES-256-GCM antes de persistirse en localStorage.

4. Manejo de Errores (OperationOutcome)

Los errores HTTP 400/409 del validador VIDA retornan un recurso OperationOutcome con issue[].diagnostics.
