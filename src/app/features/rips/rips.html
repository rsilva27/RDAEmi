8. Integración RIPS y FEV (Res. 2275 de 2023)

Paralelo al RDA clínico, el área financiera debe implementar el envío del Registro Individual de Prestación de Servicios de Salud (RIPS) como soporte de la Factura Electrónica de Venta (FEV).

Estructura del RIPS (JSON)

Contiene un objeto transaccional principal, un arreglo de usuarios, y dentro de cada usuario, un objeto de servicios que agrupa: consultas, procedimientos, urgencias, hospitalizacion, recienNacidos, medicamentos y otrosServicios.

Identificador FAB05c

El software que genera el RIPS debe estar registrado. Un error común es: "El identificador del software no corresponde...". Exige validar el código del proveedor tecnológico ante la DIAN y el Ministerio.

Recomendaciones de Arquitectura

  • Colas Asíncronas: Implementar envíos en background (RabbitMQ, Kafka, Azure Service Bus) con backoff exponencial para reintentos en caso de caídas del API del Ministerio. ¡Nunca bloquear la atención médica en tiempo real!
  • Validación Local Previa: Asegurar que el sistema HIS bloquee el registro si los códigos CUPS o CIE-10 digitados por el médico no existen en el servidor terminológico local (previamente sincronizado con Minsalud).
